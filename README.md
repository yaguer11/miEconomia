# Expenses and Savings

Aplicación web Full-Stack para gestionar y visualizar finanzas personales (gastos y ahorros).

## Stack Tecnológico

- **Frontend**: React (v19) + Vite, enrutamiento con React Router.
- **Estilos**: Tailwind CSS (v4) y Lucide React para iconos.
- **Gráficos**: Recharts para la visualización de datos financieros.
- **Backend y Base de Datos**: Supabase integrado (API, Autenticación y Base de datos PostgreSQL).
- **Utilidades**: `date-fns` para el manejo de fechas.
